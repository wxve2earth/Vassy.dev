Hi, I'm Vassy! I'm a 16-year-old developer from Europe who enjoys building things, figuring out how they work, and has a slight obsession with cats.

I started programming around three years ago out of curiosity about what goes on behind the software and websites I use every day. I initially learned Lua and Python before moving into web development with JavaScript. Lately, I've been getting into C++ and Rust, mostly because I wanted to see what programming looks like a little closer to the hardware.

These days, I'm mostly working on larger projects like Livecord, a Discord API that provides live user data, along with a bunch of smaller things I build whenever I get an idea. I usually end up learning something new with every project, whether I planned to or not. You can explore my projects on my GitHub or here on my website.

Outside of programming, I enjoy gaming, listening to music, working out, and spending time outdoors. It's nice to have a few things to switch between when I'm not busy coding.
